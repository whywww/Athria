# Athria 0.2.1-beta.3

Athria 的 Beta 预发布版本。本次提供 Windows x64 MSI 安装包。

## 本次更新

- 数据契约升级至 schema v8，数据库格式升级至 v41。
- 清理旧字段兼容、历史数据迁移及旧副本清理逻辑，统一当前数据结构。
- 更新训练计划、训练记录、健康数据及相关界面和测试。
- 增加恢复就绪度评分、训练强度记录、健康趋势与手动睡眠记录，改进训练调整校验。
- 增加紧凑训练状态读取、按日期筛选训记记录，以及计划草稿中的逐节训练编辑能力。

## 数据兼容与安装

**本版不提供旧数据库的自动迁移。旧版本数据库会被拒绝打开，不能直接沿用 beta.2 的数据库升级。**

1. 退出 Athria 和使用 Athria MCP 的 Agent，备份原数据库；保留旧版安装包以便继续使用旧数据。
2. 下载 Windows x64 MSI 和 SHA-256 校验文件，核对安装包哈希后安装。
3. 使用新建的 v41 数据库；不要删除或覆盖原数据库。需要时重新连接数据源并同步。
4. 检查 Agent 连接，重新导出配套 Skill，并按所用 Agent 的指引安装或更新。

## 当前限制

- Beta 阶段功能和数据格式仍可能变化，请保留数据库备份。
- 本次仅提供 Windows x64 安装包；Hevy 导入界面仍未开放。
- SHA-256 用于核对文件完整性，不代表安装包已完成代码签名。
