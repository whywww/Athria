# Athria 0.2.1-beta.2

Athria 的 Beta 预发布版本。本版应用与 MCP 一起升级，内置 Skill 包为 0.1.1。

## 本次更新

- **Skill 可独立在线更新**：后台检查兼容更新，设置页提供自动更新开关和手动检查。更新失败时继续使用现有 Skill，本地修改保留备份与替换流程。
- **兼容声明可单独调整**：Skill 内容不变时，可更新签名清单中的兼容范围，无需重复发布或下载相同的 Skill 包。
- **训练同步改进**：增加每日自动同步及连接后的自动同步，优化同步时间、状态和失败提示。
- **Agent 连接改进**：扩展可连接的 Agent，改进配置、重新连接和 Skill 安装指引。
- **训练记忆**：增加读取和更新训练经验记忆的 MCP 工具，配套调整档案、教练和训练计划 Skill。
- **训练与界面优化**：改善 Overview 的训练与恢复信息、计划日历和训练详情；训练时长限制改为建议性约束，并优化操作提示。

## 升级方式

1. 退出 Athria 和仍在使用 Athria MCP 的 Agent，备份当前训练数据库。
2. 安装 0.2.1-beta.2，打开原有数据库。
3. 在 Settings 中检查 Agent 连接，按界面指引重新连接或重启 Agent。
4. Claude Desktop 用户需将 Athria 导出的新版 Skill ZIP 安装到 Claude 的 Skills 设置中。

Skill 0.1.1 首次发布仅声明支持 Athria 0.2.1-beta.2 的 MCP 契约，不会推送给旧版应用。以后验证其他版本兼容后，可以单独更新签名兼容声明。

## 当前限制

- Beta 阶段功能和数据格式仍可能变化，请保留数据库备份。
- 本版仍未开放 Hevy 导入界面；训记和 Intervals.icu 同步为只读。
- 应用安装包由维护者另行构建和上传；Skill 包签名用于验证 Skill 更新来源，不代表 Windows 安装包已经完成代码签名。
- GitHub 应用发布先保留为草稿，待安装包、SHA-256 校验文件及安装验证完成后再公开发布。
