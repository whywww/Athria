Backup and Restore

Your training data is stored in one local SQLite database. Account credentials stay in your system credential manager and are only written into a backup when you ask for it.

Create a Backup

Save a self-contained copy of your active SQLite database.

If checked, connection keys are stored in the backup file unencrypted.

Restore a Backup

Choose an Athria .sqlite3 file and switch to it as your active database.

Create a New Profile

Start fresh with an empty Athria database at a location you choose. Athria will switch to it and restart; the current database file is left untouched on disk.
